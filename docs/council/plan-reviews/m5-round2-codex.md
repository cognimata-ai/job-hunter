**Remaining round-1 findings**

1. **MAJOR — Purge evidence still misses released batch submissions.** P:383, P:384; S:4088, S:4107; `backend/src/jobhunter/scoring/batches.py:1349`, `backend/src/jobhunter/scoring/batch_results.py:140`, `backend/src/jobhunter/scoring/batch_results.py:551` — Evidence is recorded only for submissions holding an `in_batch` target. Release moves targets out of that state, but released submissions remain eligible for later result retrieval or adoption. Purging those targets deletes their batch items without recording evidence; their eventual results are again classified as foreign, preventing reconciliation. — Record membership evidence for every deleted batch item whose submission can still return results, independently of the target’s current state. Test release → purge → late retrieval/adoption, while retaining the genuinely foreign-line test.

2. **MAJOR — Group cleanup neither settles deferred targets nor locks every affected member.** P:434, P:435, P:437, P:443; S:314, S:6486; `backend/src/jobhunter/dedup/representative.py:231`, `backend/src/jobhunter/dedup/representative.py:268`, `backend/src/jobhunter/dedup/groups.py:835` — `representative.reelect()` can dissolve a group, but it never calls `settle_deferred`. Consequently, the specified two-member-group test cannot obtain the promised surviving target in `pending`. Dissolution also updates surviving members, whereas the proposed chunk locks only the deleted root and its merged descendants. This acquires additional job locks after the operation owner and can reverse job-ID order. — Acquire the complete, revalidated co-member set before the owner, then use the full group-leave/settlement contract, such as `groups.leave_group(..., held=...)`. Keep the ranking bump last.

3. **MAJOR — The retry exemption still cannot work before routing.** P:289, P:557; S:6420; `backend/src/jobhunter/api/edge.py:86`, `backend/src/jobhunter/api/edge.py:220`, `backend/src/jobhunter/api/edge.py:241` — `route_label()` reads `scope["route"]`, which the downstream router populates. The proposed global-fence check runs before calling that app, so the retry request’s label is unmatched. The in-memory probe confirms this. Adding the template to `FENCE_EXEMPT_ROUTES` therefore leaves the recovery endpoint blocked; using this mechanism for login/logout also defeats their exemptions. — Match narrowly defined method/path patterns before routing, explicitly resolve the route first, or place the guard after route matching. Test through the complete middleware stack.
