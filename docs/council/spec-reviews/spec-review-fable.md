# Four-eyes review of `2026-10-16-job-hunter-design.md` — Claude Fable 5.1

Inputs: the spec (all 23 sections), consensus-v3 incl. §R, brief, facts-addendum, research/sources.md, research/tech/tech.md. Severity: **BLOCKER** = the system cannot meet a success criterion or a user decision as written; **MAJOR** = concrete integrity/silent-failure/security defect, must be fixed before implementation of that area; **MINOR** = fix during implementation.

## 1. Findings

## 3. Cost model (§21)

**Arithmetic — verified.** B: generate 2,200×$2 + 4,500×$0.20 + 2,000×$10 = $0.0253 ✓; critic 3,400×$4 + 900 + 2,000×$20 = $0.0545 ✓; revise $0.0281 ✓; funnel 0.35 + 0.12 + 0.04 = 0.51 critic calls, 0.16 revise ✓; per target 0.0253 + 0.0278 + 0.0045 = $0.0576 ✓; 3,000 × 0.0576 + ≈ $10 fixed ≈ $175–185 ✓. A $0.0863 → ≈ $260 ✓. C $0.0215 → ≈ $65 ✓. Bulk 1,000 ads: $58 online; batch $16.7 + $32.3 = $49 ✓. Cache writes $0.034/cycle ✓ — but see B1 for the cycle count.

**Assumptions.**
- *2,000 output tokens incl. thinking at medium*: optimistic. The generator schema (job facts with quotes, six criteria with ad+profile quotes, rationales ≤ 600 chars, two summaries ≤ 700 chars) is 1,200–1,800 tokens of JSON alone; Sonnet at medium adds 500–1,500 thinking tokens. Central 2,500, range 1,800–3,200.
- *Critic 35 % first round*: too low (M6); 50–60 % is the realistic union of T2/T3/T5/T8 as specified.
- *Critic after every revision*: reasonable and required by the convergence rule; cheap because revisions are rare.
- Realistic B at 3,000 targets: $0.075–0.09/target ⇒ $225–270/month. The gap to the $100 cap is 2.5×, not 1.75×.

**Levers to bring B under ≈ $100 without weakening guarantees** (all keep: mandatory critic for validator failures, binding-capable facts, injection and not-a-job-ad; never accept by convergence; no permanent rejection):
1. **Narrow the discretionary triggers**: T2 → `|M−τ| ≤ 5 OR (straddle AND coverage < 0.7)`, T3 → `M ≥ 80`, T8 → 5 %. Critic rate ≈ 30 %. (−$0.013/target)
2. **Slim the generator output**: one summary in the UI language (≤ 400 chars), rationale ≤ 300 chars, quotes ≤ 4 per criterion. Output 2,500 → 1,600. (−$0.009)
3. **Slim the critic output**: review only non-`supported` criteria and the listed facts; explanation ≤ 300 chars. Critic output 2,000 → 1,300 at Opus. (−$0.007 at 30 %)
4. **Critic effort `low` for T2/T8-only triggers, `medium` for T5/T6/T7**: separate cache entry, −30–40 % on those calls. (−$0.004)
5. **Generator effort `low`** gated on golden-set parity (already a lever). (−$0.005)
6. **Volume**: deferred duplicates and `partial` Adzuna snippets without a full-text twin should sit in the oldest lane, not the similarity lane (they are low-coverage by construction); realistic unique full-text targets for one profile are 1,500–2,000/month, not 3,000.

With 1–4: per target ≈ $0.042; at 2,000 targets ⇒ $84 + $10 fixed ≈ $95. With 5–6 as well there is headroom for the bulk re-score after a CV change. Present these in the Scoring & models dry-run as named presets ("B-lean") so the user chooses.

## 4. Overall verdict

**NOT READY AS WRITTEN — conditional approval.** The spec is faithful to consensus-v3 and the user decisions (two deliberate deviations, both improvements), the data model is unusually complete, and the gateway/ledger discipline matches the verified research. But it cannot ship until:
- **B1** (LLM pacing) is replaced by a time-based allowance — otherwise the $100 cap is consumed within days of any backlog and the system stops ranking for the rest of the month;
- **M1–M6** are fixed (availability `unknown` dead-end and the `absent_snapshots` CHECK; user state lost on merge/tombstone; `llm_call_count` CHECK; proxy-IP login throttling; purge FK chain; critic-rate assumption).

Everything else (m1–m18) can be fixed during implementation without changing a decision. After B1 and M1–M6 are applied, I would approve.
