**Architecture:**
- **One snapshot per read.** The list, the detail and the history run in `read_snapshot(engine)`: a `REPEATABLE READ, READ ONLY` transaction that reads `ranking_state.generation` and the rows together (§14.3 L5079). Every write path that changes order or membership ends with `ranking.bump` as its last statement (§3.3.3 step 11).
- **The list walks indexes, never views.** The scored section walks `det_rank_mid` / `det_rank_low` on `det_results` (M3 Carry-forward, A1 #35); the unscored section walks the new `score_targets_unscored_rank` and, for rows without a target, `jobs_pkey` backward; the date sorts walk `jobs_list_posted_any` and `jobs_list_first_seen`. Group cards are the representative's row; deferred members never appear at top level, and non-score filters match a card when the representative or any deferred member matches (B2). `db/views.sql` stays as it is (B9).
- **Thin routes over domain functions.** Routes validate input, take the §3.3.3 locks the domain function expects, and map `Refusal`, `LookupError`, `InvariantViolation`, `FencedOut` and `TransitionConflict` to problems in one place (R6: the `Refusal` handler and `api.errors.domain_problem`, Task 1). The merge family tries up to three times on a deadlock (40P01), each try in a fresh transaction (T22-a).
- **Server-computed state for the UI.** The header strip polls one cheap composite (`GET /api/system/status`, no readiness probe, no table sizes); every banner condition is computed there and arrives as `{code, severity, params}` (D5). The UI translates codes, never server prose (D39).
- **The SPA** is React 19 with TanStack Router (code routes; filter state in validated search params) and TanStack Query, i18next, a CSP-safe subset of Radix primitives, CSS Modules on design tokens. Vite builds it in a `node:22.22.3-bookworm` stage of the app image; the api serves `dist/` from `api/static.py`, deep links fall back to `index.html` (R1).
- **Testing:** pytest on the real PostgreSQL container for every route and query (EXPLAIN plans pinned, p95 measured in `tests/perf`); Vitest + Testing Library in jsdom for components and hooks; `@playwright/test` E2E on the dev stack with the fixture sources, the fake LLM and the fake embedder; `playwright-cli` screenshots for every UI task (roadmap gate 5). No test makes a paid call.

## Review Focus

1. **A character outside the Basic Multilingual Plane before a span.** A CV or an ad description with an emoji or a mathematical letter before a highlighted span.
   - Expected: the evidence highlight in the drawer and the text-review spans cover exactly the stored characters, because the server's offsets are Unicode code points (Python `str` indices) and the UI indexes `Array.from(text)`, never UTF-16 units.
   - Pinned by Task 24 (`EvidenceHighlighter.test.tsx`: `highlights by code point after an emoji`), Task 27 (`TextReview.test.tsx`: `marks and restores a span after an emoji by code points`) and Task 6 (`test_evidence_spans_are_code_point_offsets`).
2. **The same filters written differently, and a changed filter under an old cursor.** A URL whose multi-selects are reordered, repeated or spelled with their defaults; a filter changed between "Load more" clicks.
   - Expected: equivalent queries hash equal and page on with the same cursor; a different filter answers 400 `invalid_cursor`, and the UI silently reloads page 1 instead of showing an error.
   - Pinned by Task 4 (`test_equivalent_queries_hash_equal`), Task 5 (`test_a_cursor_pages_on_under_reordered_multiselects`, `test_a_changed_filter_is_an_invalid_cursor`) and Task 23 (`JobsPage.test.tsx`: `restarts from page 1 on invalid_cursor`).
3. **A job that was merged away under the user.** A bookmarked `/?job=123`, a drawer open while another tab confirms the group, a Save click on a card whose job was just merged.
   - Expected: the detail answers 404 with `merged_into_job_id` and the drawer reopens on the survivor; an action on the merged job writes no `user_job_actions` row and answers the same 404.
   - Pinned by Task 6 (`test_a_merged_job_is_404_with_its_survivor`), Task 7 (`test_actions_racing_a_merge_write_no_row_for_the_merged_job`) and Task 24 (`DetailDrawer.test.tsx`: `reopens on the survivor of a merged job`).
4. **Markup in ad text and user text.** A title `Dev <img src=x onerror=alert(1)>`, a description with `<script>`, a note with HTML, a server `detail` with angle brackets.
   - Expected: everything renders as text; no element is created from it; outbound links keep `rel="noopener noreferrer nofollow"`.
   - Pinned by Task 22 (`JobCard.test.tsx`: `renders a title with markup as text`, `outbound links carry rel`) and Task 24 (`DetailDrawer.test.tsx`: `renders description markup as text`).
5. **A tab left open with nothing but polls.** The header polls every 60 s for 13 hours.
   - Expected: the session's idle expiry does not slide on polls (`X-JH-Background: 1`), so the next user action after 12 h answers 401 and the UI goes to Login keeping the URL, then back.
   - Pinned by Task 17 (`test_a_background_request_does_not_slide_the_session`), Task 20 (`client.test.ts`: `a background call sends X-JH-Background`) and Task 32 (E19).
